# P7-05 / P7-06 / P10-06 — Vidéos marketing avec HyperFrames

**Statut** : proposé (à valider) · **Date** : 2026-09-27 · **Branche prévue** : `chore/P7-05-hyperframes-socle` puis `feat/P7-06-video-presentation` · Hors ROADMAP à ce jour : ce plan propose les entrées à y ajouter.

## Objectif
Produire les vidéos de communication de Trouvio (présentation sur l'accueil, formats courts pour le lancement) avec HyperFrames (compositions HTML + GSAP rendues en MP4), **sans toucher au runtime de l'application** ni à sa porte de qualité.

HyperFrames est un outil de production de contenu, pas une dépendance du produit : aucune ligne dans `src/`, aucune dépendance dans le `package.json` racine, rien dans l'image Docker.

## Découpage proposé (entrées ROADMAP)
- **P7-05** Socle vidéo HyperFrames : ADR 0009, projet autonome `marketing/video/`, exclusions (TS, ESLint, Prettier, git), télémétrie coupée, règle `.claude/rules/video.md`, mise à jour de `CLAUDE.md`. *Dépend de* : P0-05 (tokens, polices, logos). *Accept.* : `hyperframes doctor` et `hyperframes check` verts sur une composition témoin aux couleurs de `tokens.json` ; `pnpm verify` inchangé (même durée à ±10 %, aucun fichier de `marketing/` analysé).
- **P7-06** Vidéo de présentation (30–45 s, 16:9) intégrée à l'accueil. *Dépend de* : P7-01 (accueil en ligne en local), P1-05 (CSP). *Accept.* : `check` vert (dont contraste WCAG), vidéo ≤ 5 Mo, sous-titres `.vtt`, affiche (poster), `prefers-reduced-motion` respecté, LCP de l'accueil non dégradé (Lighthouse avant/après), aucune donnée réelle à l'écran.
- **P10-06** Kit de lancement : 3 à 5 formats courts (9:16 et 1:1) générés par variables (`render --batch`). *Accept.* : rendus conformes aux durées et formats annoncés, relus et approuvés par Kwasi avant diffusion.

- CSP (`proxy.ts`, P1-05) : `media-src 'self'`.

## Approche
1. **ADR 0009 d'abord.** Il fixe que HyperFrames est un outil de production, hors runtime, isolé dans `marketing/video/`. Il interdit tout rendu ou envoi vers un service tiers sans décision explicite.
2. **Socle.** `npx hyperframes@<version> init marketing/video`, version épinglée et `--skill` non renseigné. `hyperframes telemetry disable`, et `HYPERFRAMES_NO_TELEMETRY=1` dans les scripts. `hyperframes doctor --json` doit renvoyer `ok`.
3. **Charte.** Un script `marketing/video/scripts/tokens.mjs` génère `brand/tokens.css` à partir de `docs/design/tokens.json`, pour que les vidéos ne codent aucune couleur en dur (même règle que l'app). Il se relance quand les tokens changent.
4. **Isolation vérifiée.** On mesure `pnpm verify` avant et après, puis `pnpm lint` et `tsc`. On contrôle qu'aucun chemin `marketing/` n'apparaît dans leurs sorties.
5. **Boucle de production (P7-06 et suivantes)**, alignée sur les skills installés :
   - Brief (`BRIEF.md`) : message, public, durée, format. Kwasi le valide.
   - Choix du workflow : `product-launch-video` (depuis l'URL locale de l'accueil) ou `faceless-explainer` (flux « sources officielles → note IA → digest »).
   - Recherche au catalogue avant toute animation écrite à la main (`hyperframes catalog --query …`).
   - Écriture, puis `hyperframes check`, puis `preview`, puis **approbation de Kwasi**, puis `render --quality delivery`.
   - Vérification avec `ffprobe` (durée, fps, poids), puis compression H.264 + WebM et génération de l'affiche.
6. **Intégration web (P7-06)** : voir la section « Fichiers touchés ».

# Règles vidéos (HyperFrames) — ADR 0009

## Tests et vérifications (définis avant le code)
- **Socle (P7-05)**
  - `hyperframes doctor --json` → `ok: true`.
  - `hyperframes check` vert sur la composition témoin.
  - `render --quality draft` → fichier non vide ; `ffprobe` : durée = `data-duration`.
  - `grep` : aucune couleur hexadécimale en dur dans `marketing/video/compositions/`.
- **Non-régression** : `pnpm verify` vert, durée comparable ; `git status` propre après un rendu (renders ignorés) ; `pnpm install --frozen-lockfile` à la racine n'installe pas `hyperframes`.
- **Sécurité et vie privée** : `hyperframes telemetry status` → désactivée ; aucune clé ni `.env` dans `marketing/` ; `pnpm audit` du sous-projet sans vulnérabilité haute.
- **P7-06**
  - Lighthouse de l'accueil avant/après : LCP ≤ 2 s en 4G, sans régression.
  - Axe : sous-titres présents, contrôles accessibles au clavier.
  - Poids de `public/video/*` ≤ 5 Mo par fichier.
  - E2E Playwright : la section vidéo s'affiche avec son poster, la vidéo n'est pas chargée avant l'interaction (`preload="none"`), et n'est pas lue automatiquement si `prefers-reduced-motion`.

## Risques
- **Porte de qualité polluée** (HTML/JS de compositions analysés par ESLint, TS ou Prettier) → exclusions explicites et contrôle avant/après.
- **Dépendance lourde** (navigateur headless, FFmpeg) → sous-projet isolé, absent de la CI par défaut et de l'image Docker.
- **Dérive de version** : le CLI évolue vite (0.8.x) → version épinglée ; montée volontaire via `hyperframes upgrade --project . --check`, puis `check`.
- **Poids du dépôt** (vidéos binaires) → seuls les rendus finaux compressés sont commités, avec un budget de 5 Mo par fichier ; pas de LFS pour l'instant.
- **Vie privée / RGPD** : télémétrie, rendu cloud HeyGen, TTS distant → désactivés ou soumis à décision (règle + ADR).
- **Droits** : musiques et images → licence consignée ; aucune marque tierce hormis les sources officielles.
- **CSP stricte (P1-05)** : `<video>` sans `media-src` → bloqué ; à ajouter et tester.
- **Promesse produit** : une vidéo qui montrerait une candidature automatique contredirait CLAUDE.md §1 → relecture du brief.

## Décisions à valider
1. **Emplacement** : `marketing/video/` dans ce dépôt (recommandé : accès direct aux tokens et aux logos) ou un dépôt séparé.
2. **Numérotation** : P7-05 (socle), P7-06 (présentation), P10-06 (kit de lancement), ou tout regrouper en une seule tâche.
3. **Calendrier** : socle après P0-05 (recommandé, la charte existe alors) ; vidéos après P7-01.
4. **CI** : pas de job vidéo (recommandé au début) ou un job `hyperframes check` déclenché seulement sur `marketing/video/**`.
5. **Hébergement des rendus** : `public/video/` servi par le VPS (recommandé, ≤ 5 Mo) ou un hébergement externe (YouTube, CDN).
6. **Voix off** : aucune au départ (sous-titres seulement) ; TTS local si besoin plus tard.
