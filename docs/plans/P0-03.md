2. **Tests d'abord** : `page.test.tsx`, `server.test.ts`, `accueil.spec.ts` écrits et vus en échec pour la bonne raison.
3. Projets Vitest : `*.test.ts` → node, `*.test.tsx` → jsdom ; `globals: false`, tests colocalisés.
