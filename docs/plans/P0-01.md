## Approche
**Installation manuelle calquée sur le gabarit officiel `app-empty/ts` de create-next-app 16.3.6** : le CLI refuse un dossier non vide, et une copie depuis un dossier temporaire n'apporterait que du risque. (Repli possible : CLI dans le scratchpad avec `--no-tailwind --empty --skip-install`, copie de 5 fichiers.)
1. Branche depuis `main` à jour.
2. `package.json` : scripts `dev`, `build`, `start`, `lint` (`eslint . --max-warnings=0`), `typecheck` (`next typegen && tsc --noEmit`, nécessaire dans un clone neuf), `format`, `format:check`, `verify` **partiel** (`lint + typecheck + format:check + build`, P0-03 ajoutera `test`), `prepare` (active le hook pre-push, sans effet hors dépôt git). `packageManager`, `engines` (node ≥ 22.13, pnpm ≥ 10.26).
3. `tsconfig.json` : gabarit + alias `@/*` + `strict` + `noUncheckedIndexedAccess`, `noImplicitOverride`, `noFallthroughCasesInSwitch`, `noImplicitReturns`, `noPropertyAccessFromIndexSignature`, `forceConsistentCasingInFileNames`. Non retenus : `noUnused*` (déjà dans ESLint), `exactOptionalPropertyTypes` (revu en P1).
4. Installation des dépendances aux versions ci-dessus ; chaque script d'installation de dépendance tranché explicitement dans `allowBuilds`.
5. `next.config.ts` : `agentRules: false`, `poweredByHeader: false`, `typedRoutes: true`. Pas de `output: 'standalone'` (P10-02 : il dégraderait `pnpm start`).
6. ESLint flat : configs Next (core-web-vitals + typescript) + `no-explicit-any`, `ban-ts-comment`, `no-unused-vars` en erreur, `consistent-type-imports`, `no-floating-promises`, `no-misused-promises` (règles typées) ; dans `src/` : `no-console` (warn/error permis), `process.env` interdit hors `src/lib/env.ts`, `react/no-danger` ; directives inutiles signalées ; Prettier en dernier. Les mêmes interdits que les hooks Claude, appliqués aussi aux humains et à la CI.
7. Prettier : Markdown, `docs/`, `prompts/`, `evals/`, `.claude/`, `public/`, migrations exclus ; `pnpm format` initial.
8. `pnpm install` → hook git actif.
9. README, ROADMAP, section « Réalisé ».

Commits : `chore: initialiser Next.js 16 (App Router, TS strict, src/)` · `chore: ESLint et Prettier` · `chore: activer le hook pre-push via prepare` · `docs: …`.

## Risques (traités dans le plan)
- `next dev` ajoute un bloc à `CLAUDE.md` (code `generate-agent-files` de next 16.3.6, vérifié) → `agentRules: false` + contrôle `git status`.
- `guard-bash` refuse toute commande contenant la clé de configuration des hooks git → `package.json` écrit avec les outils d'édition ; vérification par `git rev-parse --git-path hooks`.
- `stop-verify` lancera `typecheck` en fin de tour dès l'installation → `next typegen` dans le script.
- `format.sh` formate chaque fichier édité une fois Prettier installé → exclusions dans `.prettierignore` (dont le prompt publié).
- Dependabot (P0-04) proposera TS 7 et ESLint 10, incompatibles → règles d'ignore à prévoir.
