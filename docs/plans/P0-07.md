**Documentation de Claude Code** (code.claude.com, pages permissions et sandboxing) :
- `ls`, `cat`, `head`, `tail`, `grep`, `find`, `wc`… forment un **jeu en lecture seule intégré**, exécuté sans demande quels que soient les réglages. Ce jeu n'est pas configurable.
  - **Conséquence** : retirer `Bash(grep *)` de `allow` ne change rien. Seuls une règle `ask`/`deny` ou le hook agissent.
- Les globs sans guillemets sont admis sans demande pour les commandes dont toutes les options sont en lecture seule.
- Un `xargs` sans option est retiré avant la comparaison : `Bash(grep *)` autorise `xargs grep …`.
- `find -exec` et `-delete` ne sont jamais couverts par une règle `allow` : ils demandent toujours confirmation.
- Les règles `deny` de Read s'appliquent :
  - aux outils de fichiers ;
  - à `cat`, `head`, `tail`, `sed` et `tee` lorsqu'ils **nomment** le fichier ;
  - aux redirections `<` et `>`.
  - Elles ne s'appliquent **pas** à `grep -r pattern .`, ni aux sous-processus qui ouvrent eux-mêmes des fichiers (node, python). La doc renvoie au bac à sable pour une vraie application.
- **Bac à sable (Seatbelt sur macOS, rien à installer)** :
  - les règles `deny` de Read sont **fusionnées** dans `sandbox.filesystem.denyRead`, appliqué par l'OS à tout processus Bash et à ses enfants ;
  - `allowUnsandboxedCommands: false` ferme l'échappatoire `dangerouslyDisableSandbox`.
- Une décision de hook ne contourne jamais une règle `deny`/`ask`. Un hook qui refuse l'emporte sur `allow`.
- Pour Grep et Glob, la doc dit seulement que les règles `deny` de Read s'appliquent au dossier cherché. Le comportement sur un `.env.local` ignoré par git est **à vérifier**.

## Risques
- **Hook contournable par obfuscation volontaire.** Il est présenté comme un filet ; la frontière est P0-08. Le code exécuté par `pnpm test`/`dev`/`build` lit `.env.local` : c'est un résiduel documenté.
- **Faux positifs gênants.** Messages avec alternative ; contre-épreuves calquées sur les commandes des skills.
- **Portabilité** (bash 3.2 et grep BSD contre bash 5 et grep GNU). Classes POSIX seulement ; Q8.
- **DSN réel de l'utilisateur non conforme** (forme ancienne). Il le vérifie par `pnpm dev`, sans lecture du fichier par Claude. Repli : élargir le motif, après décision.
- **Ruleset** : `PUT` remplace `rules`. Sauvegarde, `jq`, vérification et retour arrière (voir plus bas).
- **`medium_or_higher`** : PR bloquées, alertes à écarter avec justification.
- **`trustPolicy`** : installation ou Dependabot bloqués ; `trustPolicyExclude`. Dependabot peut ignorer le réglage.
- **Push sans gitleaks local** : D5 et relecture ciblée. Un faux jeton poussé resterait dans l'historique (pas de force-push).
- **Éditions de hooks, settings et workflows** : confirmation humaine à chaque fois (`guard-files`).
